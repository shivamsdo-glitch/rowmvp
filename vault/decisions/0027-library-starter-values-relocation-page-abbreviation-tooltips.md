# ADR 0027 — Starter Library values, a page for each relocation, abbreviation tooltips

**Status:** accepted and built 2026-10-22 (user feedback on the demo).

## Decisions
1. **No dropdown opens empty.** Every Library list the forms use now ships with starter values (`Domain/Common/DefaultLibrary`): cure status, appraisal / amount / review types, review recommendation, mode of contact, easement type, offer / settlement types, counteroffer and JAT responses, demo and disposition lists, displacee status / interest, eligibility type, conveyance type, fund type, title companies, document folder structure and properties, and longer contact-type and address-type lists. The values are the **agency's to change**; none is a legal requirement (same rule as ADR 0010). Only `parcel_status` (the parcel status list, filled by `DefaultParcelRules`) and the three free-text fields (CAD number, segment, priority) have no list.
2. **Existing agencies get them too.** `TenantProvisioner.EnsureLibraryAsync` was add-only per *field*, so lists created empty by earlier versions stayed empty. It now also fills a system list that has **no value rows at all**. Values are never deleted (only switched off), so "no rows" means nobody ever configured the list; an edited, extended or switched-off list is never touched.
3. **A relocation opens on its own page.** *(Superseded by ADR 0028: it now opens inside the Relocation tab, as every record does, and the stand-alone route was removed.)* `/parcels/$parcelId/relocations/$relocationId` shows the whole case (every section, agents, contacts, eligibility, contact log, status notes), its Payments panel and its attachments, with a breadcrumb and "Back to the parcel" (which lands on the Relocation tab: the parcel route takes an optional `?tab=`). The Relocation tab's list and the Relocations work screen both have a real **Open** link to it; the old pencil that filled a form at the bottom of the tab is gone. Adding a relocation stays inline on the tab. A role that can read but not change the Relocation tab sees the page read-only (fields disabled, no Save). Access is the existing `parcelrelocation` page key; no new key.
4. **Abbreviations explain themselves.** `lib/abbreviations.ts` holds one dictionary; `<Explained text>` / `<Abbr>` (`components/ui/abbr.tsx`) wrap any known upper-case abbreviation in a hover tooltip (and an `aria-description`, so accessible names are unchanged). It is applied centrally: form field labels, checkbox labels, table column headers, section legends, page titles and subtitles. Adding a term to the dictionary explains it everywhere. Terms the source documents never spell out (**JAT**, **PDB**) say so in their tooltip rather than guess; **GF** (Guaranty File number), **CAD** (Central Appraisal District) and **GIN** (General Information Notice) are the standard meanings and are open to the agency to correct.

## Not changed
Library values are free text on the records (the API does not check them against the Library), so nothing about saved data changes.
